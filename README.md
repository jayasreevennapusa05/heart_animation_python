# ❤️ My Heart Beat Animation

A beautiful animated beating heart created using HTML and CSS.

## ✨ Features

- ❤️ Animated beating heart
- 💓 Smooth heartbeat effect
- 🎨 Beautiful gradient background
- ✨ Glowing heart effect
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📁 Project Structure

heart_animation/

├── index.html
├── style.css
└── README.md

## 🚀 How to Run

1. Download the project folder.
2. Open the project folder.
3. Double-click on `index.html`.
4. The heart animation will open in your web browser.

## ❤️ Animation

The project displays a glowing red heart with a continuous heartbeat animation.
